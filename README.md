# React To-Do App

A simple **To-Do application built with React** to practice core front-end concepts such as localStorage and state management

🔗 **Live Demo:** https://jordymurgueitio.github.io/to-do-app/


## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Persist tasks using **localStorage**
- Clean and responsive UI


## What I Focused On

This project was built to strengthen my understanding of **React fundamentals**:

- Managing state with `useState.`
- Syncing state with **localStorage**
- Handling user events and conditional rendering
- Keeping components simple and readable


## Tech Stack

- React
- JavaScript (ES6)
- HTML5
- CSS3
